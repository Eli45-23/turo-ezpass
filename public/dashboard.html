  3. 3. For each vehicle, enter:

    • • Vehicle Description - e.g., "2024 Toyota Camry"
System supports all configurations:
• Plate-Only tolling (no transponder needed)
• E-ZPass/Transponder tolling
• Mixed setup (some vehicles with transponders, others plate-only)

  1. 1. Go to the Uploads CSV page.
  2. 2. Upload files
    • • Turo CSV this file should start with trip_earnings_export
    • • E-ZPass CSV this file should start with Transaction_Report
  3. 3. Press Run Matcher
  4. 4. Wait till the Matcher is done Matching before leaving that page.

WHAT IS TOLL MATCHER?

?

What is it?

The Toll Matcher is the core intelligence of this application. It automatically matches your E-ZPass toll transactions to your Turo trips based on date/time overlaps, license plates, and transponder data.

⚙

How it works

  1. 1. Analyzes trip timeframes from your Turo CSV (start/end dates)
  2. 2. Cross-references toll timestamps from your E-ZPass CSV
  3. 3. Matches license plates using your transponder mappings
  4. 4. Smart detection of tolls that occurred during active trips
  5. 5. Categorizes results as Trip Tolls, Personal Tolls, or Late Tolls
🧠

Smart matching logic

✅ Trip Tolls

Tolls that occurred during an active Turo trip timeframe with matching plate/transponder

👤 Personal Tolls

Tolls that occurred outside of any trip timeframe (your personal driving)

⏰ Late Tolls

Tolls that match a trip timeframe but the trip was already submitted/invoiced

💎

Why it's powerful

  • • 100% accuracy: Never manually sort through hundreds of toll transactions again
  • • Time-saving: What used to take hours now takes seconds
  • • Multi-vehicle support: Handles multiple cars with different transponders seamlessly
  • • Smart categorization: Automatically separates business vs. personal tolls
  • • Late detection: Catches tolls that post after trip completion
🚀

How to run the matcher

  1. 1. Upload your Turo trips CSV and E-ZPass CSV files
  2. 2. Make sure your transponder mappings are set up
  3. 3. Click "Run Matcher" on the Upload page
  4. 4. Wait for processing to complete (usually under 30 seconds)
  5. 5. Review results in the Trips page

Pro tip: The matcher gets smarter with more data! Upload regular E-ZPass exports to maintain accuracy and catch late-posting tolls.

WHAT IS LATE TOLL DETECTOR?

?

What is it?

The Late Toll Detector is an automated system that continuously monitors for toll transactions that post after you've already submitted an invoice for a trip. This helps prevent you from missing tolls that could have been reimbursed by Turo.

⚙

How it works

  1. 1. When you upload new E-ZPass data, the system checks all transactions
  2. 2. It identifies any tolls that fall within the timeframe of trips you've already submitted invoices for
  3. 3. These "late tolls" are automatically flagged and moved to the Late Tolls tab
  4. 4. You can then submit these additional tolls to Turo for reimbursement
!

Why it matters

  • • Maximize reimbursements: Catch tolls that post days or weeks after your trip
  • • Save money: Avoid paying out-of-pocket for tolls Turo should cover
  • • Stay organized: All late tolls are clearly separated and easy to find
  • • Peace of mind: Never worry about missing a toll again
📍

Where to find late tolls

Late tolls are automatically organized for you in the Trips page under the "Late Tolls" tab.

Pro tip: Check the Late Tolls tab regularly after uploading new E-ZPass data to ensure you don't miss any reimbursable tolls!
